# 阅读功能 71–83 完成记录

日期：2026-09-22。

## 完成范围

- **71 链接预览**：初始复制目标页，连续滚动按需加载邻页，最多保留 3 页；支持调整大小、固定、独立历史与目标栏适配。Option 单击链接直接分屏，Command 单击原位跳转；预览按钮或 B / Shift+B 从当前位置向右 / 向下分屏。
- **73 工作区**：每窗多具名工作区，支持创建、重命名、切换和移动 PDF；同文件阅读状态独立，批注与撤销共享。关闭窗口保留工作区组，切换与重启恢复完整分屏布局。
- **74 翻译**：T 打开 Apple 翻译小窗，默认自动识别原文并译为简体中文，可切换目标语言；点击写入为原选区新建译文高亮评论，保留已有批注，同一结果只写一次。要求 macOS 15+，应用最低版本保持 macOS 14。
- **75–76 目录**：按焦点阅读区顶部的页内位置跟随当前章节；自动展开并保持可见，手动浏览与筛选时暂停。O 聚焦当前可用目录搜索，方向键选择、Enter 跳转、Esc 取消。
- **77–78 文档切换**：两种 tab 悬停显示完整 PDF 文件名；Ctrl+Tab 使用跨当前窗口所有工作区的 MRU 列表，支持松 Ctrl 确认、反向循环与方向键。最近文件和 W 最近窗口支持定向分屏，保留来源窗口；列表分屏快捷键可自定义。
- **79–80 阅读**：手动缩放后切换模式适应新布局宽度并保留实时位置；竖直模式上下键 / J K、Book 左右键 / H L 直接翻页，保留触摸板页内平移与边界翻页。
- **82 页码**：每个 pane 右下角常驻实际页序 / 双页范围与总页数，点击就地输入跳页。
- **83 分屏**：B / Shift+B 递归向右 / 向下分屏，支持四区及更多，受最小可读尺寸限制；Ctrl+H/J/K/L 方向聚焦，Cmd+W 关闭当前区，Cmd+T 放大 / 还原，新空白 tab 改为 Cmd+Option+T。普通 tab 切换保留原分屏组，快速分屏始终新增阅读区。
