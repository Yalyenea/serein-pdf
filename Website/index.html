A few practical things.

Will it run on my Mac?

Serein requires an Apple silicon Mac with macOS 14 or later. Selection translation uses Apple’s translation service and requires macOS 15 or later.

How do I install it?

Open the downloaded DMG and drag Serein into Applications. This build is not notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway.

Apple’s installation guide ↗
Is Serein free?

Yes. Serein is free and open source under the GPL-3.0 license. You can browse the code, report a bug, or contribute on GitHub.

Where do my notes go?

Saved highlights and comments are written to your PDF. You can also export annotations as Markdown, plain text, or JSON, or export a clean PDF copy.
