A few useful things

Make yourself at home.

A short guide to reading with Serein.

InstallationReadingAnnotationsShortcutsSettingsHelp

01 / Installation

Your first read.

  1. Download the latest DMG from GitHub Releases. Requires macOS 14 or later on Apple silicon.
  2. Open the DMG and drag Serein into Applications.
  3. Launch Serein, then press ⌘O to open a PDF or a folder of PDFs.

Current builds are not notarized by Apple. If macOS blocks the first launch, review Apple’s instructions and verify that you trust the download before opening it.

Apple’s opening instructions ↗

On first launch, Serein asks for access to user folders so it can reopen your PDFs across launches and reinstalls.

02 / Reading

Find your place. Keep it.

Use the right sidebar for the outline, page thumbnails, search results, or annotations. Search the current document with ⌘F, or all PDFs in the current window with ⌘⇧F.

Switch between sidebar tabs and titlebar tabs from View. Single-page, two-page, and book layouts are also available there.

For comparison, press ⌘⌃\ and choose another document or the same PDF. Use View to arrange panes side by side or stacked. Each pane keeps its own reading position.

03 / Annotations

Leave a note for later.

Select text and press A to highlight, U to underline, or S to strike through. While highlight mode is active, 1, 2, and 3 select pink, yellow, and green. Esc leaves annotation mode.

In v0.7.0, use M or the annotation’s context menu to add or edit a comment. Press ⌘S to save changes into the PDF.

Use File → Export Highlights to export Markdown, plain text, or JSON. Export All Open Highlights collects annotations across the current window. Export Clean Copy creates a separate PDF without user annotations.

05 / Settings

Make it yours.

In Settings → General, choose your light and dark themes, reading defaults, and sidebar widths. In Library, add the folders where you already keep your PDFs.

Advanced settings are stored locally in the file below. Quit Serein before editing it, then reopen the app. Library folder paths must be absolute.

~/Library/Application Support/Serein/config.toml

Settings → General also lets you disable the optional Codex integration. Sending content to Codex happens only when you invoke its commands.

06 / Help

Something not quite right?

Open an issue on GitHub with your macOS version, Serein version, and steps to reproduce. Remove private filenames, paths, and document content before sharing a screenshot or sample.
